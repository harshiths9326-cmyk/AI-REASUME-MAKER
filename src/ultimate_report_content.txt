# AI RESUME MAKER - COMPREHENSIVE INTERNSHIP REPORT

## 1. FRONT MATTER

### 1.1 ABSTRACT
The AI Resume Maker is an intelligent, web-based application designed to automate and professionalize the process of resume creation. Developing a high-quality resume is often a hurdle for students and freshers due to formatting complexities and a lack of understanding of industry standards. This project addresses these challenges by providing a user-friendly platform built on Next.js, TypeScript, and Supabase. The system features dynamic template switching, real-time preview, secure cloud storage, and high-fidelity PDF generation. By leveraging a modular architecture and cloud-native services, the application ensures scalability, performance, and accessibility across all devices. This report documents the end-to-end development life cycle, from requirement analysis and system design to implementation and deployment.

### 1.2 PREFACE
This project was undertaken during my internship at NH Internships. The goal was to build a real-world productivity tool that solves a genuine problem while adhering to professional software engineering standards.

# 2. INTRODUCTION & BACKGROUND

## 2.1 OVERVIEW
In the modern job market, a resume is more than just a list of qualifications; it is a marketing tool that represents a candidate's professional identity. However, the manual creation of resumes remains a tedious task for many. Users often struggle with word processors, alignment issues, and selecting appropriate layouts. The AI Resume Maker aims to solve these pain points by offering a structured, automated approach to resume building.

[IMAGE: landing_page_screenshot_1778698938455.png | Figure 1: The AI Resume Maker Landing Page with Cyberpunk Aesthetics]

## 2.2 PROBLEM DEFINITION
Traditional methods of resume creation involve using desktop word processors like Microsoft Word. These tools, while powerful, require significant manual effort for formatting. Beginners often face:
- Inconsistent spacing and alignment.
- Difficulty in organizing technical projects and certifications.
- Lack of professional-grade templates.
- No central place to store and update multiple versions of a resume.

# 4. SYSTEM REQUIREMENT ANALYSIS

## 4.1 FUNCTIONAL REQUIREMENTS
1. User Authentication: Secure login/signup.
2. Data Persistence: Resumes must be saved and retrievable.
3. Live Preview: Instant feedback on data entry.
4. Template Switching: Swap designs without data loss.
5. PDF Export: High-fidelity generation.

The system must satisfy the following requirements:
- Functional: User registration, data entry, template selection, preview generation, PDF download.
- Non-functional: Responsiveness, sub-second latency for preview updates, 99.9% uptime for database connectivity.

# 7. TECHNICAL IMPLEMENTATION

## 7.1 DATABASE SCHEMA
The database is structured to support relational data for complex resumes.
```sql
CREATE TABLE resumes (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES auth.users(id),
  data JSONB NOT NULL,
  template_id TEXT DEFAULT 'modern',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## 7.2 API ROUTES (api/save-resume/route.ts)
```typescript
export async function POST(req: Request) {
    const { id, data } = await req.json()
    const { data: { user } } = await supabase.auth.getUser()
    const { data: result, error } = await supabase
        .from('resumes')
        .upsert({ id, user_id: user.id, data, updated_at: new Date() })
}
```

# 12. APPENDICES

## 12.1 SOURCE CODE: MAIN BUILDER (app/builder/page.tsx)
```tsx
"use client"
import { useState, useEffect } from "react"
import { initialResumeData, ResumeData } from "@/lib/types"

function BuilderContent() {
    const [data, setData] = useState<ResumeData>(initialResumeData)
    useEffect(() => {
        const savedData = sessionStorage.getItem("resume_builder_data")
        if (savedData) setData(JSON.parse(savedData))
    }, [])

    const updateData = (newData: Partial<ResumeData>) => {
        setData((prev) => ({ ...prev, ...newData }))
    }

    return (
        <div className="grid grid-cols-1 lg:grid-cols-2 gap-6 h-full">
            <ResumeForm data={data} updateData={updateData} />
            <ResumePreview data={data} />
        </div>
    )
}
```
